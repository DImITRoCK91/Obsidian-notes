**Аргументы командной строки** (command-line arguments) — это данные, которые передаются программе **при запуске**, прямо в команде.
![[Pasted image 20260923004809.png]]
// Скомпилирует и запустит программу
При таком запуске в метод main попадает массив строк
// например: args[0] = "0.4"

Можно выделить следующие особенности при работе с аргументами командной строки:
- Тип данных всегда String
- Разделитель - пробел между аргументами
- Доступ осуществляется через массив args[]
- Длина - args.length 

Поскольку args[] - это строки, то их нужно преобразовать:
```java
double x = Double.parseDouble(args[0]); // Метод превращает строку в double
```

Также используется обработчик ошибок (если строка не является числом)

```java
try {
    x = Double.parseDouble(args[0]);
    y = Double.parseDouble(args[1]);
    z = Double.parseDouble(args[2]);
} catch (NumberFormatException e) {
    System.out.println("Ошибка: аргументы должны быть числами.");
    return;
}
```

Также можно выделить стандартный приём в CLI, это справка (или же help, --help)
```java
if (args.length > 0 && (args[0].equals("help") || args[0].equals("--help"))) {
    printHelp();
    return;
}
```
Выводит следующий текст:

  Справка:
  java Main                - ввод данных через консоль
  java Main <x> <y> <z>    - передача значений через аргументы
  java Main help           - вывод справки
  java Main --help         - вывод справки

Вывод: используя аргументы командной строки можно ускорить процесс проверки различных данных, ну и самый главный плюс - повышается скорость ввода
