# 1. Как добавить Java в path

1) В поиске пишем "переменные среды", далее выбираем пункт "Изменение системных переменных среды" // уменьшить размер скриншотов

![[Obsidian_SKyMcYWjrL.png|484]]

2) В открывшемся окне переходим в пункт "Переменные среды..."

![[SystemPropertiesAdvanced_jEHbZ3XN47.png|416]]

3) В окне "Переменные среды", раздел "Системные переменные", выбираем "Создать..."
4) Вводим путь к JDK (обычно путь к папке "bin")

![[SystemPropertiesAdvanced_VcBXGZNKMK.png|413]]

5) После этого можно проверить версию JDK + JRE в командой строке
// **javac -version** и **java -version**![[WindowsTerminal_WVgkTk2rDD.png]]
# 2. Работа с командной строкой

1) Смена каталога: **cd**
	- cd C:\Projects // переход в папку
	- cd .. // переход на уровень выше
	- cd ~ // переход в домашний каталог
2) Просмотр содержимого: **dir** либо **ls** (но только в powershell)
	- Вывод список файлов и подкаталогов в указанном каталоге![[WindowsTerminal_CV61IxZBOj.png]]
3) Очистка содержимого всего вывода и ввода терминала: **cls**
4) Горячие клавиши при работе с терминалом:
	- ctrl + l - очистка как команда cls
	- Стрелки вверх/вниз на клавиатуре - листать историю команд
	- **Tab** - (автодополнение) - дополняет имя файла, каталога или команды по первым введённым символам // Повторное нажатие **Tab** перебирает варианты
# 3. Компиляция и запуск Java

1) Переходим в диск d, так как там находится файл .java
![[WindowsTerminal_3maqMoWpyb 1.png]]

2) Переходим в конкретную директорию, где располагается файл .java
![[WindowsTerminal_qZf0dq6OKj 1.png]]

3) Компилируем файлы java (У нас их два, потому что используется дополнительный модуль) // **javac название_файла.java**
![[WindowsTerminal_NgeF5CgOht.png]]
4) После компиляции появляется Main.class — байт‑код, исполняемый JVM.
5) Тут мы и получаем ответ на вопрос, что нам обязательна нужна виртуальная машина Java для запуска скомпилированных программ
// javac — компилятор, превращает .java в байт-код .class.
// java — лаунчер, который запускает JVM (Java Virtual Machine) и передаёт ей .class-файл.
![[WindowsTerminal_PYLu3J3zLC.png]]

Пометка: Java проверки `assert` по умолчанию отключены. Запускать программу с флагом `-ea` (enable assertions)
