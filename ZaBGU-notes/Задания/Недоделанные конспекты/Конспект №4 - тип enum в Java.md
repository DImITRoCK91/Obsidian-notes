
## 1. Что это?

`enum` (перечисление) — это специальный тип данных в Java, который представляет **фиксированный набор именованных констант** . В отличие от других языков, где enum — это просто "именованные числа", в Java `enum` — это **полноценный класс**, который может иметь поля, методы и конструкторы .

**Ключевые факты:**
*   Все перечисления неявно наследуются от `java.lang.Enum` .
*   Конструктор перечисления всегда `private` (или package-private). Вы не можете создать новый экземпляр enum через `new` .
*   Константы перечисления по соглашению пишутся ЗАГЛАВНЫМИ буквами .

## 2. Когда использовать?

Используйте `enum` всякий раз, когда вам нужно представить **фиксированный набор известных значений** .

**Типичные сценарии:**
*   **Естественные перечисления:** Дни недели, планеты, времена года, стороны света.
*   **Состояния:** `STARTED`, `STOPPED`, `PAUSED`.
*   **Типы/Категории:** Уровни логирования (`DEBUG`, `INFO`, `ERROR`), типы пользователей (`ADMIN`, `USER`).
*   **Замена "магических чисел":** Вместо `int` констант (например, `public static final int RED = 1;`) используйте enum для типобезопасности .

**Почему не `int` константы?**
До Java 5 использовался "int enum pattern". У него были минусы: отсутствие типобезопасности (можно передать любое число), отсутствие пространства имен, неинформативный вывод (`1` вместо `RED`) .

## 3. Примеры

### Базовый пример
```java
public enum Day {
    SUNDAY, MONDAY, TUESDAY, WEDNESDAY,
    THURSDAY, FRIDAY, SATURDAY
}

// Использование
Day today = Day.MONDAY;
if (today == Day.MONDAY) {
    System.out.println("Начало недели");
}
```

### Пример с полями и методами
Enum может хранить дополнительные данные и иметь логику .

```java
public enum Planet {
    MERCURY(3.303e+23, 2.4397e6),
    EARTH(5.976e+24, 6.37814e6);

    private final double mass;   // в килограммах
    private final double radius; // в метрах

    // Конструктор неявно private
    Planet(double mass, double radius) {
        this.mass = mass;
        this.radius = radius;
    }

    public double surfaceGravity() {
        return 6.67300E-11 * mass / (radius * radius);
    }
}
```

### Использование в `switch`
Enum идеально подходит для `switch` (синтаксис без указания имени класса в `case`) .

```java
Day day = Day.FRIDAY;
switch (day) {
    case MONDAY:
        System.out.println("Понедельник — день тяжелый");
        break;
    case FRIDAY:
        System.out.println("Пятница!");
        break;
    default:
        System.out.println("Обычный день");
}
```

## 4. Полезные встроенные методы

У каждого enum есть автоматически сгенерированные методы :

*   **`values()`**: Возвращает массив всех констант в порядке объявления. Удобно для циклов `for-each`.
    ```java
    for (Day d : Day.values()) {
        System.out.println(d);
    }
    ```
*   **`valueOf(String name)`**: Возвращает константу по её строковому имени.
    ```java
    Day d = Day.valueOf("MONDAY");
    ```
*   **`ordinal()`**: Возвращает порядковый номер константы (начиная с 0). *Не рекомендуется использовать для бизнес-логики, так как номер меняется при перестановке констант.*
*   **`name()`**: Возвращает имя константы в виде строки.

## 5. Важные ограничения

1.  **Нельзя наследовать:** Enum не может расширять другой класс (так как уже неявно наследует `java.lang.Enum`). Но может реализовывать интерфейсы .
2.  **Нельзя создавать экземпляры:** Кроме предопределенных констант, других объектов этого типа создать нельзя (исключение — рефлексия, но это не рекомендуется).
3.  **Изменяемость:** Хотя enum — это класс, его константы должны быть неизменяемыми (поля `final`), чтобы сохранять предсказуемость.

## 6. Бонус: Enum как Singleton

Поскольку enum гарантирует, что экземпляр создается ровно один раз (при загрузке класса), он является потокобезопасным и идеально подходит для реализации паттерна **Singleton** (Одиночка) .

```java
public enum Singleton {
    INSTANCE;
    
    public void doSomething() {
        // логика
    }
}
```
