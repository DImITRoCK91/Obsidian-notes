## 1. Общее представление

В Java форматированный вывод реализован через два основных метода:

- **`System.out.printf(String format, Object... args)`** — выводит отформатированную строку в стандартный поток вывода.
- **`String.format(String format, Object... args)`** — возвращает отформатированную строку (не выводит её).

Оба метода используют один и тот же синтаксис строки формата.

```java
System.out.printf("Формат", аргументы);
String s = String.format("Формат", аргументы);
```

---

## 2. Синтаксис строки формата

Спецификатор формата имеет вид:

```
%[flags][width][.precision]conversion
-
%[флаги][ширина][.точность]тип
```

Где:
- `%` — начало спецификатора;
- `flags` — флаги (например, `-`, `+`, `0`, `,`, `(`); // Флаги - это необязательные символы в спецификаторе формата, которые меняют способ отображения значения
- `width` — минимальная ширина поля;
- `.precision` — точность (для вещественных — число знаков после запятой);
- `conversion` — тип преобразования (`d`, `f`, `s`, `c`, `b`, `x`, `e`, `n` и др.).

---

## 3. Основные спецификаторы

// Таблица была сгенерирована искусственным интеллектом

| Спецификатор | Назначение                            | Пример                                  |
| ------------ | ------------------------------------- | --------------------------------------- |
| `%d`         | целое число (десятичное)              | `printf("%d", 42)` → `42`               |
| `%f`         | вещественное число                    | `printf("%f", 3.14)` → `3.140000`       |
| `%s`         | строка                                | `printf("%s", "Java")` → `Java`         |
| `%c`         | символ                                | `printf("%c", 'A')` → `A`               |
| `%b`         | логическое значение                   | `printf("%b", true)` → `true`           |
| `%e`         | вещественное в экспоненциальной форме | `printf("%e", 1234.5)` → `1.234500e+03` |
| `%x`         | целое в шестнадцатеричной системе     | `printf("%x", 255)` → `ff`              |
| `%o`         | целое в восьмеричной системе          | `printf("%o", 8)` → `10`                |
| `%%`         | символ `%`                            | `printf("100%%")` → `100%`              |
| `%n`         | перевод строки (платформонезависимый) | —                                       |

## 4. Работа с целыми числами

```java
int n = 42;
System.out.printf("%d%n", n);           // 42
System.out.printf("%5d%n", n);          // "   42" (ширина 5, выравнивание справа)
System.out.printf("%-5d|%n", n);        // "42   |" (выравнивание слева)
System.out.printf("%05d%n", n);         // "00042" (ведущие нули)
System.out.printf("%,d%n", 1234567);    // "1,234,567" (разделитель групп)
System.out.printf("%+d%n", n);          // "+42" (знак всегда)
System.out.printf("%x %o%n", n, n);     // "2a 52"
```

## 5. Работа с вещественными числами

```java
double x = 3.14159265;

System.out.printf("%f%n", x);           // 3.141593 (по умолчанию 6 знаков)
System.out.printf("%.2f%n", x);         // 3.14
System.out.printf("%10.3f%n", x);       // "     3.142" (ширина 10, 3 знака)
System.out.printf("%-10.3f|%n", x);     // "3.142     |"
System.out.printf("%e%n", x);           // 3.141593e+00
System.out.printf("%.0f%n", x);         // 3
System.out.printf("%,.2f%n", 1234567.89);// 1,234,567.89
```

Для `float` и `double` по умолчанию выводится **6 знаков после запятой**.

## 6. Работа со строками и символами

```java
String name = "Java";
System.out.printf("Привет, %s!%n", name);   // Привет, Java!
System.out.printf("%10s|%n", name);         // "      Java|" (справа)
System.out.printf("%-10s|%n", name);        // "Java      |" (слева)
System.out.printf("%.2s%n", name);          // "Ja" (обрезает до 2 символов)
System.out.printf("%c%n", 'A');             // A
```
## 7. Порядок аргументов и индексы

Можно ссылаться на аргументы по индексу (нумерация с 1):

```java
System.out.printf("%1$s %2$d %1$s%n", "X", 7);  // X 7 X
```

## 8. Флаги

| Флаг | Значение |
|------|----------|
| `-` | выравнивание по левому краю |
| `+` | всегда показывать знак |
| `0` | дополнение нулями |
| `,` | разделитель групп разрядов |
| `(` | отрицательные числа в скобках |
| `пробел` | пробел перед положительным числом |

Пример:
```java
System.out.printf("%+,.2f%n", 12345.678);  // +12,345.68
```

## 9. `String.format` и `System.out.printf`

```java
// printf — сразу вывод
System.out.printf("Итого: %.2f руб.%n", 199.9);

// String.format — формирование строки
String result = String.format("Итого: %.2f руб.", 199.9);
System.out.println(result);
```

`String.format` удобен, когда строку нужно:
- сохранить в переменную;
- записать в файл;
- передать в исключение и т.д.

## 11. Мини-пример

```java
public class Format {
    public static void main(String[] args) {
        String name = "Ноутбук";
        int qty = 3;
        double price = 54999.99;

        System.out.printf("%-12s %5s %12s%n", "Товар", "Кол-во", "Цена");
        System.out.printf("%-12s %5d %12.2f%n", name, qty, price);
        System.out.printf("Итого: %,12.2f%n", qty * price);

        String line = String.format("%s x%d = %.2f",
                name, qty, qty * price);
        System.out.println(line);
    }
}
```

Вывод:
```
Товар        Кол-во         Цена
Ноутбук          3     54999,99
Итого:     164 999,97
Ноутбук x3 = 164999,99
```
