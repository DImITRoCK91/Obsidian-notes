## 1. Основные характеристики класса String

`String` — это финальный класс в пакете `java.lang`, представляющий неизменяемую (immutable) последовательность символов в кодировке UTF-16 . Это означает, что после создания объекта String его значение не может быть изменено. Любая операция, которая «изменяет» строку, на самом деле создаёт новый объект String.

Строковые литералы (например, `"Hello"`) автоматически являются экземплярами класса String. Класс реализует интерфейсы `Serializable`, `Comparable<String>` и `CharSequence`.

## 2. Создание строк

Основные способы создания объекта String:

```java
// Через литерал (предпочтительный способ)
String s1 = "Java";

// Через конструктор с массивом символов
char[] chars = {'J', 'a', 'v', 'a'};
String s2 = new String(chars);

// Через конструктор с массивом байтов
byte[] bytes = {74, 97, 118, 97};
String s3 = new String(bytes);

// Пустая строка
String s4 = new String();
```

## 3. Основные операции и методы

### 3.1 Получение информации о строке

| Метод | Описание | Возвращаемый тип |
|-------|----------|------------------|
| `length()` | Возвращает количество символов (кодовых единиц) в строке | `int` |
| `isEmpty()` | Проверяет, является ли строка пустой (`length() == 0`) | `boolean` |
| `charAt(int index)` | Возвращает символ по указанному индексу (индексация с 0) | `char` |

Пример:
```java
String str = "Привет";
int len = str.length();        // 6
char ch = str.charAt(0);       // 'П'
boolean empty = str.isEmpty(); // false
```


### 3.2 Сравнение строк

**Важно:** для сравнения содержимого строк всегда используйте `equals()`, а не `==` (который сравнивает ссылки).

| Метод | Описание |
|-------|----------|
| `equals(Object obj)` | Сравнивает строки с учётом регистра |
| `equalsIgnoreCase(String str)` | Сравнивает строки без учёта регистра |
| `compareTo(String str)` | Лексикографическое сравнение (возвращает отрицательное, ноль или положительное число) |
| `compareToIgnoreCase(String str)` | Лексикографическое сравнение без учёта регистра |

Пример:
```java
String a = "Java";
String b = "java";
a.equals(b);           // false
a.equalsIgnoreCase(b); // true
a.compareTo(b);        // отрицательное число (заглавные буквы идут раньше строчных)
```


### 3.3 Поиск в строке

| Метод | Описание |
|-------|----------|
| `indexOf(String str)` | Возвращает индекс первого вхождения подстроки (или -1, если не найдено) |
| `lastIndexOf(String str)` | Возвращает индекс последнего вхождения подстроки |
| `contains(CharSequence s)` | Проверяет, содержится ли подстрока в строке |
| `startsWith(String prefix)` | Проверяет, начинается ли строка с указанного префикса |
| `endsWith(String suffix)` | Проверяет, заканчивается ли строка указанным суффиксом |

Пример:
```java
String text = "Hello, World!";
int pos = text.indexOf("World");    // 7
boolean hasHello = text.contains("Hello"); // true
boolean starts = text.startsWith("He");    // true
boolean ends = text.endsWith("!");         // true
```


### 3.4 Извлечение подстрок

| Метод | Описание |
|-------|----------|
| `substring(int beginIndex)` | Возвращает подстроку от указанного индекса до конца |
| `substring(int beginIndex, int endIndex)` | Возвращает подстроку от `beginIndex` (включительно) до `endIndex` (исключительно) |

Пример:
```java
String s = "Программирование";
String sub1 = s.substring(0, 4);  // "Прог"
String sub2 = s.substring(4);     // "раммирование"
```


### 3.5 Преобразование регистра

| Метод | Описание |
|-------|----------|
| `toLowerCase()` | Преобразует все символы в нижний регистр |
| `toUpperCase()` | Преобразует все символы в верхний регистр |

```java
String mixed = "Java";
mixed.toLowerCase(); // "java"
mixed.toUpperCase(); // "JAVA"
```


### 3.6 Замена и удаление символов

| Метод | Описание |
|-------|----------|
| `replace(char oldChar, char newChar)` | Заменяет все вхождения символа |
| `replace(CharSequence target, CharSequence replacement)` | Заменяет все вхождения подстроки |
| `replaceAll(String regex, String replacement)` | Заменяет по регулярному выражению |
| `trim()` | Удаляет пробельные символы в начале и конце строки |
| `strip()` | Аналогично `trim()`, но учитывает Unicode-пробелы (Java 11+) |

```java
String s = "  Java  ";
s.trim();                    // "Java"
s.replace('a', 'o');         // "  Jovo  "
"a-b-c".replace("-", "+");   // "a+b+c"
```


### 3.7 Разбиение строки

| Метод | Описание |
|-------|----------|
| `split(String regex)` | Разбивает строку по регулярному выражению на массив строк |

```java
String csv = "apple,banana,cherry";
String[] fruits = csv.split(",");
// fruits = ["apple", "banana", "cherry"]
```


### 3.8 Объединение строк

| Метод | Описание |
|-------|----------|
| `concat(String str)` | Присоединяет строку в конец |
| `String.join(CharSequence delimiter, CharSequence... elements)` | Статический метод для соединения строк с разделителем |

```java
"Hello".concat(" World"); // "Hello World"
String.join("-", "a", "b", "c"); // "a-b-c"
```


## 4. Конкатенация и оператор `+`

Java предоставляет специальную поддержку оператора `+` для конкатенации строк. При использовании `+` с объектами, не являющимися строками, автоматически вызывается метод `toString()` .

```java
String result = "Число: " + 42; // "Число: 42"
```

Внутренне конкатенация реализуется через `StringBuilder` (или `StringBuffer` в старых версиях), поэтому при большом количестве операций сложения рекомендуется явно использовать `StringBuilder` для производительности .

## 5. Важные замечания

1. **Неизменяемость:** после создания строки её нельзя изменить. Методы вроде `toUpperCase()`, `replace()`, `substring()` возвращают **новую** строку, а не модифицируют исходную .

2. **`==` vs `equals()`:** оператор `==` сравнивает ссылки на объекты, а `equals()` — содержимое. Для строк практически всегда нужно использовать `equals()`.

3. **NullPointerException:** передача `null` в методы String (кроме проверок на null) вызывает `NullPointerException` .

4. **Кодировка UTF-16:** String хранит символы в UTF-16. Некоторые символы (эмодзи, редкие иероглифы) занимают две кодовые единицы (`char`), поэтому `length()` может не совпадать с количеством видимых символов.
