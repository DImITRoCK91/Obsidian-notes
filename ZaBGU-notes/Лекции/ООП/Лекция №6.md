# Исключения (исключительные ситуации)
Исключительные ситуации (исключения) в Java — это незапланированные события и ошибки, которые происходят во время работы программы и нарушают её нормальный ход.

Можно построить иерархию исключений:

Error: критичные системные сбои
Exception: обычные исключения, делятся на два типа:
- Checked (проверяемые)
- Unchecked (непроверяемые)


Исключение - специальное значение, которое мы возвращаем из функции.

Пути:
Можно создать переменную r, в которую функция будет записывать либо 0, либо 1, чтобы узнать успех выполнения программы
