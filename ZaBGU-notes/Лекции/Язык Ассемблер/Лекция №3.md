Команда ADD 01, 02
01 - приёмник
02 - источник
01: = 01 + 02
```ASM
mov ax, 8
mov cx, 6
mov dx, ex
add dx, ax
```
Чтобы не потерять значение приёмника можно использовать промежуточные регистры (в этом примере dx)

Команда SUB 01, 02
вычитает из источника приёмник, помещает значение в приёмник
01:= 01 - 02
Если мы выполняем вычитание одинаковых переменных, то может произойти переполнение сетки. То есть результат не помещается в отведённые под него разряды.
Чтобы сохранить результат, который не помещается в разряды, в АСМ есть механизм, который называется парой регистра. Пара - два регистра, которые хранят одно число (условно пара обозначается символом :)
Для того, чтобы избежать переполнение используются спец. команды ADC (сложение)
CBB (вычитание)
Команды также имеют два операнда, только добавляют значение флага C (работают в паре с обычными сложениями и вычитаниями)
